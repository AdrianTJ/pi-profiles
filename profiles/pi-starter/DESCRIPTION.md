# pi-starter

Baseline starter set for a fresh machine.

Use it when: setting up a new machine or checking what a plain, well-equipped pi install looks like. It is the older full-fat set; `daily` is the leaner successor.

Note: this one uses the non-lite packages (`pi-subagents`, `pi-web-access`) where `daily` uses `pi-subagents-lite` and `pi-web-lite`.
