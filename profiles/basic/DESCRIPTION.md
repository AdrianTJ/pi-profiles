# basic

Plain pi plus two extensions: web search and subagents.

Use it when: you want stock pi behavior — normal built-in tools, skills, prompts — with nothing added beyond `pi-web-access` (`web_search`, `fetch_content`, `source_check`, `get_search_content`) and `pi-subagents` (`subagent` and friends).

Not installed: the lean extras from `daily` (fff grep, ask-user-question, btw, goal/todo overlays), and `pi-tasks`/`ponytail` from the base set. No `defaultTools` override, no approval gating, no RALPH loop — native pi tool behavior throughout.
